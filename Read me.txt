MOUSEPILOT
Mouse shortcuts for your Windows PC

START
Double-click MousePilot.exe. Keep the web folder beside the executable.
The local dashboard opens in your default browser. No installation is needed.

MAKE A RULE
Choose New shortcut. Add mouse inputs in order, select an installed application
or enter a website, and save. The change takes effect immediately.
Example: Left, Left, Left, Right -> Claude.
Middle means pressing the scroll wheel; Wheel up/down means turning it.
Use Browse if an application is not listed.

USE IT
Move focus away from the dashboard and perform your sequence. Each input
must arrive within your chosen gap. After a launch there is a 1.5-second
cooldown. Rules ignore synthetic mouse inputs generated by other software.
The gesture test area lets you practice without opening the application.

The mouse keeps its normal behavior: clicks still reach the foreground app,
and wheel turns still scroll. A single left-click or wheel rule can launch
very frequently. Longer sequences or a middle-button sequence are easier
to keep separate from everyday use. Conflicting sequence prefixes are
rejected so a shorter rule cannot fire before a longer rule is complete.

Rules pause while the dashboard has focus so editing is comfortable.
Closing the browser leaves MousePilot running in the system tray.
Use the tray menu to reopen the dashboard, pause all rules, or quit.
Start with Windows is optional and off until you enable it.

LOCAL DATA
Rules and custom app choices are stored in %LOCALAPPDATA%\MousePilot.
The dashboard listens only on localhost, requires a session token for
its API, and does not send your settings or clicks to a cloud service.
Only recent rule activity is shown; raw mouse coordinates are not saved.
To remove the app, disable Start with Windows, quit from the tray, then
delete this folder. Your settings can be removed separately if desired.

SOURCE
Editable C# source is in src; dashboard HTML/CSS/JavaScript is in web.
Build.ps1 compiles with the .NET Framework compiler included in Windows.
Run it from PowerShell to rebuild after quitting the running application.

Windows lock screens, sign-in screens, and secure system prompts are
outside the normal desktop and are not supported.

Implementation reference: Microsoft's LowLevelMouseProc documentation
https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc
