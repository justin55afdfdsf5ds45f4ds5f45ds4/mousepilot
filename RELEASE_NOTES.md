## MousePilot 1.0.0

The first public release of MousePilot: create mouse gestures in a local dashboard and apply them instantly.

- Left/right/middle clicks, wheel up/down, and mouse side buttons.
- Launch installed Windows apps, Store apps, custom shortcuts, and websites.
- Gesture practice, action testing, configurable timing, conflict detection, and global pause.
- System tray operation, persistent local rules, and optional start with Windows.
- MIT-licensed source, automated tests, and a dependency-free Windows build.

### Install

Download `MousePilot-1.0.0-windows.zip`, extract every file, and open `MousePilot.exe`. Keep the `web` folder alongside it. Configure your first rule in the dashboard; new installations start empty.

The Windows executable is unsigned. `SHA256SUMS.txt` is provided to verify the download. Windows with .NET Framework 4.x is required. Mouse inputs retain their normal behavior, and rules pause while the dashboard is focused.
